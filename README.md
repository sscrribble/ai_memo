# AI 메모

적기만 하면 AI가 알아서 분류하는 메모 앱. 서버 하나에 휴대폰·태블릿·노트북·PC가 모두 접속해 실시간으로 동기화됩니다.

## 기능

- **AI 자동 분류**: 할 일 / 장보기 / 아이디어 / 정보·참고 / 일기·생각 / 기타
  - 제목·태그를 자동으로 만들고, "내일 3시", "다음주 금요일" 같은 날짜를 실제 날짜로 바꿉니다
  - 장보기 메모는 물건별 체크리스트로 나눕니다 ("우유 2개, 계란" → 우유(2개), 계란)
  - 분류가 틀리면 배지를 눌러 직접 바꾸면 됩니다 (이후 AI가 덮어쓰지 않음)
- **반복 일정**: "매주 월요일 9시 회의", "평일마다 약", "격주 토요일", "매달 25일 카드값", "매달 말일", "매년 3월 5일 생일"
  - 체크하면 끝나지 않고 다음 회차로 넘어갑니다 (되돌리기 가능). 캘린더에 앞으로의 날짜가 흐리게 표시됩니다
  - 반복하는 장보기 목록은 '완료 항목 지우기'를 해도 지워지지 않고 체크만 풀려 다음에 다시 씁니다
- **할 일**: 지난 일 / 오늘 / 예정 / 날짜 없음으로 묶고, 완료한 일은 접어 둡니다. ⋯ 메뉴에서 '내일로 미루기'
- **캘린더**: 날짜가 있는 메모를 월간 달력으로 보기
- **장보기**: 마트 구역별(채소·과일 → 정육·수산 → 냉장·유제품 …)로 모아 보거나 메모별로 보기, 체크한 항목은 한 번에 지우기
- **편집**: ⋯ 메뉴에서 내용·날짜·시간·반복을 고칩니다 (직접 정한 값은 AI가 덮어쓰지 않음)
- **고정·링크·태그**: 중요한 메모는 맨 위에 고정, 메모 속 링크는 눌러서 열기, #태그를 누르면 그 태그로 검색
- **삭제 되돌리기·휴지통**: 삭제 직후 '되돌리기', 지운 메모는 30일 동안 휴지통에 보관
- **오프라인**: 서버에 연결되지 않아도 마지막으로 본 내용이 그대로 보이고, 장보기 체크·메모 작성·수정이 됩니다. 연결되면 자동으로 보냅니다
  - 안드로이드 앱과 `https://` 주소에서는 서버가 꺼져 있어도 앱이 열립니다. 브라우저로 `http://` 주소를 쓰면, 열어 둔 화면에서만 오프라인으로 쓸 수 있습니다
- **백업**: 매일 자동 백업(최근 14개), 파일로 내보내기·가져오기
- **화면**: 어두운 화면이 기본이고, 해/달 버튼으로 밝은 화면으로 바꿀 수 있습니다
- **알림**: 서버가 일정을 확인해 자동으로 알려줍니다 (설정 버튼에서 시간 변경·끄기)
  - 아침 요약(기본 08:00): 오늘 할 일과 지난 일
  - 전날 알림(기본 20:00): 내일 일정과 마감
  - 일정 직전 알림(기본 30분 전): 시간이 정해진 일정
- **실시간 동기화**: 한 기기에서 고치면 다른 기기 화면에 바로 반영
- **안드로이드 앱**: 앱을 닫아도 일정 알림이 오는 전용 앱 ([아래](#휴대폰-앱-안드로이드)). 아이폰·태블릿은 "홈 화면에 추가"
- **보안**: 비밀번호를 10분 안에 5번 틀리면 5분 동안 로그인이 잠깁니다
- API 키가 없으면 키워드 규칙으로 분류합니다 (정확도는 떨어짐)

## 실행

### 안드로이드 휴대폰을 서버로

아이폰은 서버로 쓸 수 없습니다 (앱이 뒤에서 계속 돌 수 없음). 아래는 안드로이드 기준입니다.

**1. 앱 설치** — [F-Droid](https://f-droid.org)에서 세 앱을 받습니다. 셋 다 같은 곳에서 받아야 서로 연결됩니다.
- **Termux**: 서버가 돌아가는 곳
- **Termux:API**: 이 휴대폰에 일정 알림 띄우기
- **Termux:Boot**: 휴대폰을 껐다 켜도 서버 자동 시작 (설치 후 한 번 열어 두기)

**2. 설치** — Termux를 열고 아래 한 줄을 붙여 넣습니다. 처음엔 10분 안팎 걸립니다.

```bash
pkg install -y git && git clone https://github.com/sscrribble/ai_memo ~/ai_memo && bash ~/ai_memo/scripts/termux-install.sh
```

중간에 묻는 것:
- 접속 비밀번호: 다른 기기에서 로그인할 때 씁니다
- Claude API 키: 없으면 Enter (키워드로 분류). 나중에 `nano ~/ai_memo/.env`로 넣을 수 있습니다
- 저장소 권한: '허용'하면 백업이 휴대폰 `Documents/ai-memo-backup` 폴더에 쌓여, 앱을 지워도 남습니다

**3. 휴대폰 설정 (꼭)** — 설정 → 애플리케이션 → Termux → 배터리 → **제한 없음**. 안 하면 화면이 꺼졌을 때 서버가 멈춥니다.

**4. 접속** — 서버를 시작하면 주소가 나옵니다 (예: `http://192.168.0.23:8000`). 같은 Wi-Fi의 다른 기기에서 [안드로이드 앱](#휴대폰-앱-안드로이드)이나 브라우저로 이 주소에 들어가 로그인하면 됩니다. 밖에서도 쓰려면 [밖에서 접속하기](#밖에서-접속하기-tailscale-없이도)를 보세요.

| 하고 싶은 것 | 명령 (Termux에서) |
|---|---|
| 서버 시작 | `bash ~/ai_memo/scripts/start.sh` |
| 서버 멈춤 | `bash ~/ai_memo/scripts/stop.sh` |
| 새 버전으로 업데이트 | `bash ~/ai_memo/scripts/termux-install.sh` (설정은 그대로) |
| 밖에서도 접속 (Cloudflare 터널) | `bash ~/ai_memo/scripts/termux-tunnel.sh` |
| 비밀번호·API 키 바꾸기 | `nano ~/ai_memo/.env` 후 서버 다시 시작 |
| 자동 시작된 서버의 기록 보기 | `tail -f ~/ai_memo/data/server.log` |

서버 휴대폰에도 안드로이드 앱을 깔았다면, 알림이 두 번 오지 않게 `.env`에 `MEMO_TERMUX_NOTIFY=0`을 넣어 Termux 알림을 끄세요.

브라우저에서 `http://서버주소:8000` 접속. 데이터는 `data/memo.db`(SQLite) 하나에 저장됩니다.

## 백업

- **자동**: 하루 한 번 `data/backups/memo-날짜.db`로 복사하고 최근 14개만 남깁니다 (`MEMO_BACKUP_DIR`, `MEMO_BACKUP_KEEP`으로 변경)
- **복구**: 서버를 끄고, `data/memo.db-wal`·`data/memo.db-shm` 파일이 있으면 지운 다음, 백업 파일을 `data/memo.db`로 복사하고 다시 켭니다
- **파일로**: 설정 → 백업 → 내보내기로 JSON 파일을 받고, 다른 서버에서 가져오기로 넣습니다. 이미 있는 메모는 건너뜁니다
- 휴대폰 설치 스크립트에서 저장소 권한을 허용했다면 백업은 휴대폰 `Documents/ai-memo-backup` 폴더에 쌓입니다

## 휴대폰 앱 (안드로이드)

**[앱 내려받기 (ai-memo.apk)](https://github.com/sscrribble/ai_memo/raw/main/apk/ai-memo.apk)** — 휴대폰 브라우저에서 이 링크를 누릅니다. (안드로이드 8.0 이상)

1. 내려받은 파일을 열면 "출처를 알 수 없는 앱" 허용을 묻습니다 → 허용 → 설치. (플레이 스토어 밖에서 받는 앱이라 Play 프로텍트가 확인을 요청할 수 있습니다)
2. 처음 열면 **서버 주소**를 넣습니다. 서버 휴대폰에서 서버를 시작할 때 나온 주소입니다 (예: `http://192.168.0.23:8000`, Tailscale이면 `http://100.x.x.x:8000`, 터널이면 `https://memo.내도메인.com`)
3. 로그인하고 **알림 허용**, **배터리 사용 제한 해제**를 허용합니다. 그래야 앱을 닫아도 일정·마감 알림이 제때 옵니다

- 화면과 기능은 서버에서 불러옵니다. 그래서 서버만 업데이트하면 앱도 새 기능이 생깁니다 (앱을 다시 설치할 필요 없음)
- 서버가 꺼져 있거나 밖에 있어도 앱이 열리고, 마지막으로 본 메모를 보고 고칠 수 있습니다 (연결되면 자동 반영)
- 연결이 끊겼던 동안 보낸 알림도 다시 연결되면 받습니다 (최근 12시간)
- 서버 주소는 설정 → 앱 → 서버 주소 '바꾸기'에서 바꿉니다
- 아이폰 앱은 맥과 애플 개발자 계정(연 13만 원 정도)이 있어야 만들 수 있어 없습니다. 아이폰은 Safari에서 서버 주소를 열고 공유 → "홈 화면에 추가"를 쓰세요

## 밖에서 접속하기 (Tailscale 없이도)

같은 Wi-Fi(집)에서만 쓴다면 아무것도 필요 없습니다. 밖(LTE·회사 등)에서도 쓰려면 아래 중 하나가 필요합니다.

| 방법 | 비용 | 다른 기기에 할 일 | 특징 |
|---|---|---|---|
| **Tailscale** | 무료 | 기기마다 Tailscale 앱 설치·로그인 | 가장 쉬움. 인터넷에 공개되지 않아 안전 |
| **Cloudflare 터널** | 도메인 값 (연 1~2만 원) | 없음 (주소만 입력) | `https://` 고정 주소. 웹 푸시·아이폰 홈 화면 앱 알림까지 됨 |
| 공유기 포트포워딩 | 무료 | 없음 | 비추천: 공유기 설정, 보안(HTTPS) 직접 처리, 통신사에 따라 불가 |

Cloudflare의 무료 임시 주소(`trycloudflare.com`)는 서버를 켤 때마다 주소가 바뀌고 실시간 동기화가 동작하지 않아 쓰지 않습니다.

**Cloudflare 터널 연결하기**
1. [Cloudflare](https://dash.cloudflare.com)에 가입하고 도메인을 등록합니다 (Cloudflare에서 사도 됩니다)
2. Zero Trust → Networks 에서 **터널(Tunnel)을 만들고** 종류는 Cloudflared 를 고릅니다. 설치 명령(`cloudflared service install eyJ…`)이 나오면 복사해 둡니다 ([안내](https://developers.cloudflare.com/tunnel/setup))
3. 같은 화면의 **Public Hostname**에 주소(예: `memo.내도메인.com`)를 정하고, Service 는 `HTTP` / `localhost:8000` 으로 저장합니다
4. 서버 휴대폰(Termux)에서 아래를 실행해 복사한 명령과 주소를 붙여 넣습니다

```bash
bash ~/ai_memo/scripts/termux-tunnel.sh
```

이제 어디서든 `https://memo.내도메인.com`으로 접속합니다. 서버를 시작할 때마다 터널도 같이 켜집니다. 공개 주소이므로 비밀번호를 꼭 쓰세요 (5번 틀리면 잠깁니다).

PC·클라우드 서버라면 [Tailscale](https://tailscale.com), Cloudflare 터널, 또는 HTTPS 프록시(Caddy 등)를 쓰면 됩니다.

## 알림 받는 방법

| 방법 | 조건 | 설정 |
|---|---|---|
| 화면 안 알림 | 앱을 열어 둔 동안 | 없음 |
| **안드로이드 앱** (앱을 닫아도 옴) | `http://` 주소여도 됨 | 앱에서 알림 허용·배터리 사용 제한 해제 |
| 웹 푸시 (앱을 닫아도 옴) | **HTTPS 주소**로 접속. 아이폰·아이패드는 "홈 화면에 추가"로 설치한 앱에서만 | 설정 → "이 기기에서 알림 받기" 켜기 (기기마다 한 번) |
| 서버 휴대폰 알림 | 서버를 안드로이드 Termux에서 실행, Termux:API 앱과 `pkg install termux-api` | 없음 (자동) |
| ntfy 앱 | 받을 기기에 ntfy 앱 설치 | `MEMO_NTFY_URL` 설정 후 앱에서 같은 주제 구독 |

- 웹 푸시 내용은 받는 기기까지 암호화되어 중간 푸시 서비스가 볼 수 없습니다. ntfy는 내용이 ntfy 서버를 그대로 거칩니다.
- 완료한 일은 알리지 않고, 같은 알림은 한 번만 보냅니다. 서버가 꺼져 있던 시간의 알림은 요약은 3시간 안에 켜지면 뒤늦게 보내고, 지난 일정 알림은 보내지 않습니다.
- Termux에서 웹 푸시까지 쓰려면 `pkg install python-cryptography`가 필요합니다. 없어도 나머지 알림은 동작합니다.

## 설정 (환경변수)

| 이름 | 설명 | 기본값 |
|---|---|---|
| `MEMO_PASSWORD` | 로그인 비밀번호. 비우면 로그인 없이 접속 | 없음 |
| `ANTHROPIC_API_KEY` | Claude API 키 ([발급](https://console.anthropic.com)) | 없음 → 규칙 기반 |
| `MEMO_MODEL` | 분류에 쓸 Claude 모델 | `claude-opus-5-5` |
| `MEMO_TZ` | "오늘/내일" 계산 기준 시간대 | `Asia/Seoul` |
| `MEMO_NTFY_URL` | ntfy 알림 주소 (예: `https://ntfy.sh/긴-이름`) | 없음 |
| `MEMO_CONTACT` | 웹 푸시 서비스에 알리는 연락처 (`mailto:` 또는 `https:`) | `mailto:admin@example.com` |
| `MEMO_DB` | DB 파일 경로 | `data/memo.db` |
| `MEMO_BACKUP_DIR` | 자동 백업 폴더 | `data/backups` |
| `MEMO_BACKUP_KEEP` | 남길 백업 개수 | `14` |
| `MEMO_TERMUX_NOTIFY` | `0`이면 서버 휴대폰의 Termux 알림 끄기 (앱과 중복될 때) | `1` |
| `CLOUDFLARE_TUNNEL_TOKEN` | Cloudflare 터널 토큰 (`termux-tunnel.sh`가 넣음) | 없음 |
| `MEMO_PUBLIC_URL` | 밖에서 접속하는 주소 (시작할 때 표시만) | 없음 |

AI 호출은 메모를 저장하거나 수정할 때만 한 번씩 합니다. 비용을 더 줄이려면 `MEMO_MODEL=claude-haiku-5-5`로 바꾸세요.

## 구조

```
server/app.py         FastAPI 서버: REST API, SSE 실시간 동기화, 로그인, 알림·백업 작업
server/reminders.py   알림 시점 계산, 웹 푸시·Termux·ntfy 발송
server/recurrence.py  반복 일정 계산 (web/recur.js 와 같은 규칙)
server/classifier.py  Claude 분류(구조화 출력) + 규칙 기반 대체 분류
web/                  웹앱(PWA): 바닐라 JS, 빌드 과정 없음
scripts/              휴대폰 설치(termux-install.sh), 터널(termux-tunnel.sh), 서버 시작·멈춤(start.sh, stop.sh)
android/              안드로이드 앱: 서버 화면을 보여 주고, 닫아도 알림 받기 (빌드 방법은 android/README.md)
```
